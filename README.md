# 🎂 Happy Birthday, Rohit | A Magical Interactive Celebration

An immersive, interactive multi-stage birthday web journey built with love, featuring rich aesthetics, synthesized web audio, festive animations, and customizable memory chapters.

---

## ✨ Features

- **Act I · The Mystery Vault**: Interactive 3D gift box with floating ribbons and golden sparkles.
- **Act II · Birthday Cake Studio 🎂**: Multi-tier customizable cake with fresh berries, golden sprinkles, sweet macarons, dual sizzling sparklers, and blow-out candles with wish reveal and cake cutting!
- **Act III · The Us Quiz 💖**: Heartwarming trivia questions celebrating cherished moments.
- **Act IV · Runaway Question 🤭**: The famous playful evasive "No" button with hilarious responsive chatter.
- **Act V · Carnival Fiesta 🎈💥**: Clickable pull-string party crackers with explosive physics and a balloon popping chamber revealing secret love notes.
- **Act VI · Secret Promise 🎟️**: Realistic metallic golden scratch card voucher.
- **Act VII · Cherished Memories 📸**: Deluxe 20-photo Polaroid deck showcasing memorable pictures and captions.
- **Grand Finale · Celebration 👑🎆**: Royal birthday portrait, heartfelt letter, and launchable fireworks show!
- **Festive Ambience**:
  - Swaying party bunting & floating balloons on stage transitions.
  - Interactive golden sparkler mouse/touch particle trail.
  - Synthesized Web Audio SFX (cracker explosions, balloon pops, candle blowing puffs, sparkler sizzles, chimes).
  - Background starry galaxy with smooth 60fps canvas animation.

---

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or host it on GitHub Pages / Vercel / Netlify.

```bash
# Clone the repository
git clone https://github.com/adityashaw970/birthday.git

# Open index.html
open index.html
```
